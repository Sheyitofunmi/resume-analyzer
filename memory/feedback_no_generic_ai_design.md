User does not want generic AI SaaS designs. The project uses a bold & editorial design language instead.

**Why:** The original design had the classic AI startup look — indigo/purple gradients, pulsing dot badges, sparkle emojis (✨), rounded pill shapes, glowing shadows, and backdrop blur cards. User rejected this.

**How to apply:**

- Design palette: off-white `#F8F7F4` background, near-black `#0A0A0A` primary text, `#525252` secondary, `#E11D48` red accent
- Typography: Instrument Serif for display headings, Mona Sans for body
- Borders: flat 1px `#E5E5E5` — no soft shadows, no glow, no gradient borders
- Buttons: flat black `#0A0A0A`, square corners (2px radius), no gradients
- No: `rounded-full` pill badges, sparkle/pulsing animations for UI elements, gradient text, SVG background images, `backdrop-blur`, indigo/purple color scheme
- Cards: thin border, no shadow
- Remove emoji decorations from feature lists, badges, and CTAs
